# Bitcoin Market Sentiment vs Trader Performance Analysis

## Overview

This project analyzes the relationship between Bitcoin market sentiment (Fear & Greed Index) and trader performance using historical trading data from Hyperliquid.

The objective is to identify patterns in trader behavior and generate insights that support smarter trading decisions.

## Dataset

### 1. Bitcoin Market Sentiment Dataset

* Date
* Classification (Fear / Greed)

### 2. Hyperliquid Historical Trader Dataset

* Account
* Coin
* Execution Price
* Size USD
* Side
* Timestamp
* Direction
* Closed PnL
* Fee
* Trade ID

## Project Workflow

* Data Loading
* Data Cleaning
* Date Conversion
* Dataset Merging
* Exploratory Data Analysis (EDA)
* Sentiment-Based Performance Analysis
* Pattern Discovery
* Insight Generation

## Analysis Performed

* Trade distribution across market sentiment
* Average Profit/Loss comparison
* Buy vs Sell analysis
* Trade size comparison
* Direction-based performance analysis
* Winning percentage evaluation

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Key Insights

* Trader performance varies across Fear and Greed periods.
* Market sentiment influences trade behavior.
* Trade size and profitability show sentiment-based patterns.

## Conclusion

Market sentiment can be used as an additional signal for understanding trader behavior and improving trading decisions when combined with risk management.
